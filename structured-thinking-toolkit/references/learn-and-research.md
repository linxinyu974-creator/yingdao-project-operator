# Learn And Research

Select one primary method.

## Dual-Layer Explanation

Use when the user needs both intuition and mechanism.

Explain the subject twice: a plain layer using ordinary language and one concrete example, then a technical layer using precise terms, causal mechanism, boundaries, and common failure modes. Map the plain explanation to the technical concepts, identify the most tempting misconception, and ask or provide a transfer question that cannot be answered by repeating the analogy.

## Reverse Engineering

Use when a strong example, product, process, document, or result is available and the user wants transferable practice.

First name the problem the artifact solves. Then identify its audience, structure or sequence, key choices that create the quality gap, completion standard, and context-specific details. Produce three to five transferable rules, an execution checklist, and the smallest exercise that tests one rule.

## Longitudinal And Comparative Research

Use when the user wants a defensible account of how a product, company, person, technology, industry, or event reached its current position.

Research two axes:

- Longitudinal: origin, incentives, inflection points, successes, failures, path dependencies, and constraints.
- Comparative: select genuinely comparable alternatives, apply common dimensions, and explain adoption as well as rejection.

Prefer primary sources and original data when tools allow research. Attach source and date to consequential claims. Present conflicts side by side and mark missing evidence as unverified.

Produce a core conclusion, timeline, comparison, detailed analysis, plausible future paths with their signals, and open questions. Let requested depth determine length; never inflate the report to a fixed word count.
