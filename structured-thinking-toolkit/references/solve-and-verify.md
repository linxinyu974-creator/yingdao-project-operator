# Solve And Verify

Select the method matching the actual bottleneck. Combine methods only when the first creates an explicit input for the second.

## Evidence Audit

Use for a claim, conclusion, dataset, or proposal whose reliability matters.

Decompose it into facts, inferences, and value judgments. For each fact, inspect source quality, sample, date, and context when evidence tools are available. Grade it as verified, provisionally supported, disputed, insufficient, or false. Then test whether the facts entail the conclusion, whether correlation is being treated as causation, which alternatives were omitted, and under what conditions the conclusion fails.

Produce the reliable facts, required corrections, key inference gap, strongest defensible version, and confidence level with reasons.

## Complementary Perspectives

Use when one discipline is unlikely to cover the problem.

Choose three genuinely complementary professional lenses based on the problem's facts, goal, and constraints. Each lens independently reframes the problem, recommends a route, identifies what the others may miss, and names evidence that would change its view. Compare shared facts, real disagreements, and hidden assumptions before synthesizing a conditional recommendation, largest risk, exit condition, and first action.

Describe lenses rather than impersonating named living people or claiming access to real experts.

## First Principles

Use when the current approach shows path dependence or repeatedly patches symptoms.

Separate immovable facts, untested conventions, the true objective, and real constraints. Derive a new route from only the facts, objective, and constraints. Contrast it with the symptom-level repair, state the new route's assumptions, and give the first validation step.

## Cross-Domain Analogy

Use when the domain's standard approaches are exhausted.

Remove domain vocabulary and express the underlying structure, core conflict, and reason ordinary approaches fail. Find at least three distant domains with the same mechanism. For each, explain the mechanism, structural match, transferable part, and failure boundary. Translate the best mechanisms back into the user's constraints and propose one low-cost reversible trial.
