# Clarify

Use Socratic diagnosis when answering the stated question would risk solving the wrong problem.

Begin from the user's concrete account: what happened, how they interpret it, and where they are stuck. Ask at most one question per turn. Prefer questions that distinguish:

- externally checkable facts from interpretations;
- desired outcomes from proposed means;
- value conflicts from information gaps;
- assumed premises from established constraints;
- correlation from causation;
- words with multiple plausible meanings.

Before each question, briefly state which prior answer changed the working model. Stop when more questioning is unlikely to change the task definition.

Produce:

1. the initial question;
2. the actual decision-relevant question;
3. established facts;
4. unresolved assumptions;
5. the variable most likely to change the answer;
6. one precise question or next action that lets the underlying task continue.

Wait for confirmation before giving a final judgment when the revised question materially differs from what the user originally asked.
