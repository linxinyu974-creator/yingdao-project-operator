# 汇报要求

查看/诊断：报告观察、证据路径、未知项、未修改/未运行。

开发/修复：报告真实 app/flow/文件、调用链、最小改动、保存/编译/诊断、生效副本及未发布阶段。

真实测试：报告执行面、task/run ID、输入范围、页面/账号证据、结果内容、人工干预、失败/跳过和重试条件。

技能维护：报告源仓库、远端、Codex 安装副本、哈希比较、脚本测试、采纳/拒绝的学习候选项及未做的发布/重载。

禁止推导：py_compile→影刀诊断；CLI 成功→业务完成；Profile 连接→业务身份；文件存在→本批次完整；保存→远端/其他电脑生效；一次 PermissionError→WPS；历史额度→当前余量。未知就写 unknown，不编造 ID、次数和成功数据。
