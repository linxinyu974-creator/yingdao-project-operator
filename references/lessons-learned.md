## 已确认经验

### 影刀打开网页与外部 Chrome Profile 冲突

- 现象：出现多个 Chrome 用户环境或插件冲突。
- 根因：影刀模块和外部 Profile 启动逻辑同时竞争浏览器环境。
- 修复：明确激活目标 Profile，由 Python/浏览器连接逻辑创建网页对象，主流程保持薄。
- 适用边界：仅适用于需要复用外部 Chrome Profile 登录态的流程。

### 下载成功不等于业务导出成功

- 现象：文件存在且可打开，但只有另一业务的字段。
- 根因：页面路径或导出按钮相似，未做业务字段校验。
- 修复：同时校验页面标题、筛选条件、表头和关键字段。
- 适用边界：所有网页导出流程。

### 旧下载文件会伪装成本次导出

- 现象：导出日志显示已提交，但核对读取到的文件属于销售分析、客服模板等其他业务；或移动 Downloads 文件时出现权限/占用错误。
- 根因：按目录扫描拿到任意旧 Excel，或同名目标文件存在时直接返回；保存函数调用时点晚于浏览器落盘，单纯的“本次调用前目录快照”也可能失效。
- 修复：同时使用导出时间窗口、文件 stat 变化、写入稳定性、文件名范围和业务表头校验；目标文件存在时只接受 stat 改变后的文件，移动失败保留候选并继续轮询。
- 适用边界：浏览器自动下载、保存对话框和共享 Downloads 目录混用的流程。

### 影刀个人版额度耗尽不是业务失败

- 现象：控制台返回 `quota_limited` / `CLI quota denied`，任务没有 task ID，应用未执行。
- 根因：社区/个人版每日运行额度已用尽。
- 修复：停止运行重试，保留代码和流程状态，完成不消耗额度的语法检查、保存和静态诊断；额度重置后从整应用入口重新测试。
- 适用边界：仅适用于 CLI 明确返回额度拒绝；已有 task ID 的业务运行错误仍需按执行链排查。

### CLI 模块接口被禁用时不要猜参数

- 现象：标准模块目录或参数表单返回 `TOOL_DISABLED` / 不可读。
- 根因：当前影刀版本或运行模式未开放该接口。
- 修复：保留应用，使用已有 CodeFlow/模块，或让用户完成一次不可替代的可视化配置。
- 适用边界：接口能力随版本变化时。
