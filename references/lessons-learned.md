# 故障查表与证据边界

| 现象 | 先查 | 禁止推断 |
|---|---|---|
| health 不通 | 本地服务、版本、模式 | 不等于密码错 |
| auth 成功但业务要求登录 | 目标 Profile/站点 | 不等于影刀掉线 |
| 用户说继续且有 task | state/status/logs | 不重新 run |
| CLI 等待超时 | state/status/history | 不等于停止 |
| 秒结束无副作用 | startup/调用链 | 不报整应用成功 |
| Allowed=True/余1 | 原始时间和字段 | 不报额度耗尽 |
| quota_limited | 提交响应/task ID | 不重复撞额度 |
| 文件占用 | 自身资源/占用证据 | 不直接归因 WPS |
| A1/表头异常 | XML 实际行/业务字段 | 不只看 max_row |
| stat(None) | 首个上游错误/路径 | 不只修最后异常 |
| 仓库与安装副本不同 | 哈希/版本 | 不报已加载 |

旧经验仅在当前版本、当前调用链和证据吻合时复用；项目样本不是平台规则。报告区分观察、推断、已修改、已保存/发布、局部/整应用验证。
