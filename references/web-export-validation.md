# 网页导出与结果校验

## 页面动作

- 优先使用已有影刀浏览器元素和稳定 selector。
- 页面导航、筛选、点击和下载属于网页动作；批次、日期、文件轮询、汇总和通知属于 Python 业务逻辑。
- 下载操作应配合保存对话框处理和文件轮询，避免只等待固定秒数。

## 三层校验

1. 页面校验：URL、页面标题或关键业务标题正确。
2. 条件校验：日期、店铺、账号和筛选条件与本次任务一致。
3. 文件校验：文件出现且可读取，表头和关键字段符合需求，数据行数不是明显异常。

只有三层都通过才报告成功。文件存在但表头属于另一业务（例如出现“订单号（可发货）”而需求要求客服绩效字段）时，判定为错误导出并回溯页面路径。

## 多店铺循环

每家店铺记录独立状态：`成功`、`失败`、`跳过`。失败时保存步骤、页面或文件证据，继续下一家仅在不会复用错误登录态的前提下进行。最终输出成功数、失败数、跳过数及原因。
