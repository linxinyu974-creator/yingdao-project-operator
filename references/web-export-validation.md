# 导出与文件校验

导出前确认目标账号/Profile、业务页/iframe、查询条件、文件类型和本次唯一暂存/目标目录；首次点击前建立下载目录快照。不要把任意新 Excel 或固定 sleep 当结果。

提交后区分保存对话框、自动下载、后台队列、验证码/频率限制和未提交。使用当前版本真实保存 API；保存异常保留类型/阶段。worker USERPROFILE 可能和交互用户不同，扩大目录必须限定授权范围并核对候选来源。

候选需同时满足本次时间/请求关联、下载完成稳定、文件类型、业务表头和订单覆盖/合理行数。XLSX 可能 dimension=A1，read_only 时 reset_dimensions 后读取实际行；显式关闭 workbook。合法零结果按业务约定验收，不无限重导。

旧目标先验证归属；占用先查自身句柄再查外部。下载到唯一暂存名后验证再替换，归档失败明确报错；不在运行期间手工搬文件补结果。
